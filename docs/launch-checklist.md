# お金をもらう前の手順書

審査やお金の手続きは、持ち主(あなた)が行う。終わったら Claude に伝えれば、設定の切り替えと確認は Claude が行う。

---

## 1. バリューコマースの審査が通ったら(紹介料)

| 順番 | やること | 誰が |
|---|---|---|
| 1 | Vercel を有料プラン(Pro、月20ドル)に切り替える(下の「2.」) | あなた |
| 2 | 一休・オズモールのカードを出す: Vercel の環境変数 `OTHER_SITES_ON=1` | Claude |
| 3 | カードを押して、一休・オズモールの検索結果に飛ぶか確かめる(バリューコマースの仮ページに飛ばないか) | Claude |
| 4 | ホットペッパーの提携が承認されたら、バリューコマースの MyLink で pid を作り、`AFFILIATE_URL_TEMPLATE` に入れる | Claude |
| 5 | `/stats` で、お店・予約サイトが押された数が増えているか見る | どちらでも |

`AFFILIATE_URL_TEMPLATE` の形:
`https://ck.jp.ap.valuecommerce.com/servlet/referral?sid=3788519&pid=(ホットペッパーの pid)&vc_url={url}`

### 守ること
- 一休・オズモール: ボタンや説明文に、社名・サイト名を書かない
- ホットペッパー: 「#アフィリエイト広告」を目立たない表示にしない。クーポンのページに直接リンクしない
- 3社とも: 社名やサービス名を含む言葉で、検索広告(リスティング)を出さない

## 2. Vercel の有料プラン(Pro)への切り替え

- 理由: 無料プラン(Hobby)は、お金を得るサイトに使えない決まり。紹介料や有料機能を出す前に切り替える
- 費用: 月20ドル(約3,000円)。今のカード(JCB 末尾1040)で払われる
- 手順: Vercel → Settings → Billing → Upgrade to Pro
- 切り替えても変わらないこと: アドレス(www.tsudoro.com)、データ、今の設定
- 切り替えたら Claude に伝える(本番の動きを確かめる)

## 3. 有料機能(傾斜で割る・集金のページ)の買い切り

作ってあるが、決済の設定がまだ。そろうまでは誰でも全部使える。

### 値段の案
| 案 | 値段 | 考え方 |
|---|---|---|
| A | 980円 | 社会人の幹事が1回の会計で元が取れる額 |
| B | 480円 | 学生も買いやすい。数で稼ぐ |
| C | 学生は無料、社会人だけ 980円 | 学生向けの広がりを止めない |

C に決めて作った(2026-11-17)。値段は 500円の買い切り(`lib/billing.ts` の初期値。`PRO_PRICE` で変えられる。2026-11-17 に 980円から一時的に戻した。有料パックが「ひとりずつ催促」中心になったため)。学生とプライベートの会は無料、会社の会だけ傾斜で割るに鍵がかかる(`lib/audience.ts` の `needsPro`)。会の種類は本人が選ぶので、うそをつけば無料で使えるが、少額なので気にしない。
始める目安は、会が月に約150件(このころ、紹介料と合わせて Vercel 有料プランの費用を上回る)。

### 始めるのに必要なもの
| もの | 環境変数 | 誰が |
|---|---|---|
| Stripe のアカウントと本人確認 | — | あなた |
| Stripe の秘密鍵(sk_live_…) | `STRIPE_SECRET_KEY` | あなたがクリップボードにコピーし、Claude が入れる(画面には出さない) |
| 購入の鍵に署名する乱数 | `LICENSE_SECRET` | Claude が作る |
| 値段 | `PRO_PRICE` | あなたが決め、Claude が入れる |
| 特定商取引法の表記(名前・住所・電話・メール) | `SELLER_NAME` `SELLER_ADDRESS` `SELLER_PHONE` `SELLER_EMAIL` | あなた。住所・電話は「請求があれば遅滞なく開示」にもできる |

### 確かめること
- テスト用の鍵(sk_test_…)で、買う → 使えるようになる、までを先に試す
- 本番の鍵に替えたら、自分で1回買って、返金できるかも確かめる

### 催促をアプリにまかせる(自動でお知らせ。有料プレミアムの中心。2026-11-17)
- 集金のページで、幹事が自動でお知らせをオンにすると、払っていない人に、アプリが通知(Web Push)で知らせる。参加する人が、自分の名前を選んで「通知をオンにする」を押した端末にだけ届く。翌日・3日後・7日後。払い終わる(幹事が受け取りを記録する)と止まる
- 幹事の PayPay リンクは集金ごとに保存し、参加する人の画面に「PayPay で払う」を出す(無料)
- 本番に出す前に必要なこと:
  1. Supabase で `supabase/migrations/20261117000000_push_subs.sql` を適用する(適用前でも集金のページは開ける。通知の登録だけできない)
  2. Vercel の環境変数に `VAPID_PUBLIC_KEY` `VAPID_PRIVATE_KEY` `CRON_SECRET` を入れる(鍵は `npx web-push generate-vapid-keys`)。なければ、画面に「通知の準備がまだできていません」と出て、オンにできない
  3. Vercel の定期ジョブ(Cron)は、`vercel.json` の crons で1日1回。無料プラン(Hobby)でも1日1回までは動く
- iPhone は、ホーム画面に追加したアプリからだけ通知を受け取れる(その案内を画面に出す)。届く割合は高くない見込みなので、使われ方を見て判断する
- 無料: 集金の表づくり・PayPay リンクをのせる・ひとりずつ文を作って送る

### 有料プレミアムは月額 500円のサブスク(2026-11-17 に買い切りから変更)
- Stripe の準備(あなた): アカウントと本人確認、ダッシュボードで **カスタマーポータルを有効にする**(解約・支払い方法の変更のため)。テストモードで、申し込み → 通知のオン → 解約までを試してから、本番の鍵に替える
- 鍵(`STRIPE_SECRET_KEY` `LICENSE_SECRET`)がそろうと、買えるようになる。それまでは「申し込みの受付はもうすぐ始まります」と出る
- 解約すると、使うたびの確認(10分ごと)で、鍵が効かなくなり、デモ版に戻る
- 特定商取引法の表記は、月額・自動更新・解約の書き方に直した(販売者の名前・住所・メールは、環境変数 `SELLER_*`)。表記が正しいかは、公開前に専門家に確認するのが安全

### 方針の変更(2026-11-17 夜): 有料プレミアムの軸は、エンターテインメントに戻した
- 有料プレミアム(月額 500円)の中身は、もりあげ道具(真実か挑戦・ワードウルフ・王様ゲーム・チーム分け)と、会社の会の傾斜で割る。「催促をアプリにまかせる」は、必要性が薄いとして画面から外した(コードは残してある。上の節は参考)
- 集金の表づくりと、PayPay のリンクをのせることは無料
