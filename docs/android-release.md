# Android アプリを Google Play に出す手順

アプリのコードは `mobile/`。ここに書くのは、ストアに出すまでに人がやること。**登録・支払い・鍵の作成・提出は、ユーザー(またはオーナー)が行う。**

## 0. 先に決めること

| 決めること | 今の値 | 決める人 |
|---|---|---|
| アプリの id(ストアに出すと変えられない) | `com.tsudoro.tsudoro`(`mobile/android/app/build.gradle.kts`) | オーナー |
| Play Console のアカウントを誰の名前で作るか(開発者名がストアに出る) | 未定(issue #2) | オーナー |
| アプリでの Tsudoro+ の買い方 | 最初の版には入れない(買う画面がない) | オーナー(issue #2) |

## 1. 本番の API を出す(アプリより先)

アプリの release 版は `https://www.tsudoro.com/api/v1` を呼ぶ。今の本番にはまだ `/api/v1` がない(`notice`・`pr` を返す変更と、プライバシーポリシーの書き足しも未反映)ので、feat/mobile を master に入れて本番に出してからでないと、アプリは動かない。`pr` がないとアプリは「#アフィリエイト広告」を出さないので、ステマの決まりのためにも先に出す。本番に出すのはユーザーの「出して」のあと。

## 2. アップロード鍵を作る(1回だけ)

Play には「アップロード鍵」で署名した AAB を上げる。アプリの本当の署名は Google が持つ(Play App Signing)ので、アップロード鍵をなくしても Play Console から作り直せる。それでも、作った鍵と合言葉はパスワード管理などに保管する。

```powershell
# 鍵は mobile/android/ の外に置く(リポジトリに入れない)
keytool -genkey -v -keystore $env:USERPROFILE\keys\tsudoro-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

`mobile/android/key.properties` を作る(`.gitignore` 済み。合言葉はここにだけ書く):

```properties
storeFile=C:/Users/<ユーザー名>/keys/tsudoro-upload.jks
storePassword=<合言葉>
keyAlias=upload
keyPassword=<合言葉>
```

## 3. ビルドする

```powershell
cd mobile
fvm flutter test
fvm flutter build appbundle --release
# → mobile/build/app/outputs/bundle/release/app-release.aab
```

- 版を上げるときは `mobile/pubspec.yaml` の `version: 1.0.0+1` を上げる(`+` の後ろ = versionCode は、上げるたびに必ず増やす)
- `key.properties` がないと開発用の鍵で署名される。その AAB は Play が受け付けない

## 4. Play Console でやること

1. アカウントを作る(初回 25 ドル)。個人の開発者は、クローズドテストで 12 人以上のテスターに 14 日以上使ってもらわないと本番に出せない決まりがある(2023-11 以降に作ったアカウント。出す前に Play Console のヘルプで今の決まりを確かめる)
2. 「アプリを作成」: 名前 `Tsudoro`、言語 日本語、アプリ、無料
3. 内部テストに `app-release.aab` を上げ、自分の端末で入れて確かめる → クローズドテスト → 製品版
4. ストアの掲載情報(下の文と `mobile/store/` の画像)
5. アプリのコンテンツ(下の答え)

### 掲載の画像(`mobile/store/`。`node scripts/make-app-icons.mjs` で作り直せる)
- アイコン 512×512: `icon-512.png`
- フィーチャー グラフィック 1024×500: `feature-1024x500.png`
- スマホのスクリーンショット: `screenshots/`(1080×2160。2026-11-23 にエミュレーターで、日本語の会で撮った)。お店はホットペッパーの鍵がない開発環境の見本なので、お店の一覧が写るものは、本番の API につないだ版で撮り直してから使う

### 掲載の文(案)

- アプリ名(30字まで): `Tsudoro 飲み会の日程とお店がすぐ決まる`
- 簡単な説明(80字まで): `URLをLINEに貼るだけ。みんなが行ける日と予算を答えると、日にちとお店がすぐ決まる。登録なし・無料。`
- 詳しい説明:

```
Tsudoro は、飲み会の日程とお店がすぐ決まるアプリです。登録なし・無料で使えます。

■ 使い方
1. 幹事が候補の日を選んで、会を作る
2. できたURLを LINE のグループに貼る
3. みんなが、行ける日と予算を30秒で答える
4. いちばん良い日と、みんなに合うお店が出るので、そのまま決める
5. 「決まったよ」を送る。会計(割り勘・傾斜)もこのアプリで

■ できること
・行ける日を ○△× で集める
・いちばん多くの人が行ける日を自動で選ぶ
・みんなの予算・駅・食べたいものに合うお店を探す
・苦手なもの・アレルギーやお酒を飲まない人の数を、名前を出さずに幹事に伝える
・割り勘と傾斜(先輩・上司は多め、飲まない人は少なめ)の計算
・プライベートの会と仕事の会で、言い方や質問を変える

■ 参加する人は
アプリがなくても、届いたURLからブラウザで答えられます。

お店のページへのリンクには、提携リンク(アフィリエイト広告)を含みます。
```

### アプリのコンテンツ(Play Console の質問への答え)

- プライバシーポリシー: `https://www.tsudoro.com/privacy`
- 広告: 含まない(バナーなどの広告は出さない。提携リンクは広告 SDK ではない)
- アプリのアクセス権: すべての機能を制限なしで使える(ログインなし)
- 対象年齢: 18歳以上(お酒の席の道具のため)
- コンテンツのレーティング(IARC の質問): お酒への言及あり、お酒の販売はしない。暴力・性的な内容・ギャンブル・ユーザー間の自由なチャットはなし
- データ セーフティ:
  - 集める: 名前(ニックネーム。ユーザーが入れるもの)、そのほかユーザーが作るもの(行ける日・予算・駅・苦手なもの・ひとこと)
  - 目的: アプリの機能のため。共有(第三者への提供)はしない
  - 送るときは暗号化する(HTTPS): はい
  - 削除の依頼: プライバシーポリシーの連絡先で受け付ける
  - 位置情報・連絡先・端末の識別子・広告 ID は集めない

## 5. まだアプリにないもの(最初の版で出すかを決める)

- 届いた会の URL をタップしてアプリで開く(App Links)。アプリの側は対応済み(`AndroidManifest.xml`)。本番に `public/.well-known/assetlinks.json`(アップロード鍵ではなく、Play Console の「アプリの署名」の鍵の SHA-256)を置くと、確かめが通って直接開くようになる
- 通知(FCM)
- 集金、Play / Support(有料。issue #2 の返事待ち)
