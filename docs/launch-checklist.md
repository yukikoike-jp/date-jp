# お金をもらう前の手順書

審査やお金の手続きは、持ち主(あなた)が行う。終わったら Claude に伝えれば、設定の切り替えと確認は Claude が行う。

---

## 1. バリューコマースの審査が通ったら(紹介料)

| 順番 | やること | 誰が |
|---|---|---|
| 1 | Vercel を有料プラン(Pro、月20ドル)に切り替える(下の「2.」) | あなた |
| 2 | 一休・オズモールのカードを出す: Vercel の環境変数 `OTHER_SITES_ON=1` | Claude |
| 3 | カードを押して、一休・オズモールの検索結果に飛ぶか確かめる(バリューコマースの仮ページに飛ばないか) | Claude |
| 4 | ホットペッパーの提携が承認されたら、バリューコマースの MyLink で pid を作り、`AFFILIATE_URL_TEMPLATE` に入れる | Claude |
| 5 | `/stats` で、お店・予約サイトが押された数が増えているか見る | どちらでも |

`AFFILIATE_URL_TEMPLATE` の形:
`https://ck.jp.ap.valuecommerce.com/servlet/referral?sid=3788519&pid=(ホットペッパーの pid)&vc_url={url}`

### 守ること
- 一休・オズモール: ボタンや説明文に、社名・サイト名を書かない
- ホットペッパー: 「#アフィリエイト広告」を目立たない表示にしない。クーポンのページに直接リンクしない
- 3社とも: 社名やサービス名を含む言葉で、検索広告(リスティング)を出さない

## 2. Vercel の有料プラン(Pro)への切り替え

- 理由: 無料プラン(Hobby)は、お金を得るサイトに使えない決まり。紹介料や有料機能を出す前に切り替える
- 費用: 月20ドル(約3,000円)。今のカード(JCB 末尾1040)で払われる
- 手順: Vercel → Settings → Billing → Upgrade to Pro
- 切り替えても変わらないこと: アドレス(www.tsudoro.com)、データ、今の設定
- 切り替えたら Claude に伝える(本番の動きを確かめる)

## 3. 有料機能(傾斜で割る・集金のページ)の買い切り

作ってあるが、決済の設定がまだ。そろうまでは誰でも全部使える。

### 値段の案
| 案 | 値段 | 考え方 |
|---|---|---|
| A | 980円 | 社会人の幹事が1回の会計で元が取れる額 |
| B | 480円 | 学生も買いやすい。数で稼ぐ |
| C | 学生は無料、社会人だけ 980円 | 学生向けの広がりを止めない |

C に決めて作った(2026-11-17)。値段は 500円の買い切り(`lib/billing.ts` の初期値。`PRO_PRICE` で変えられる)に決まった。学生とプライベートの会は無料、会社の会だけ傾斜で割る・集金のページに鍵がかかる(`lib/audience.ts` の `needsPro`)。会の種類は本人が選ぶので、うそをつけば無料で使えるが、少額なので気にしない。
始める目安は、会が月に約150件(このころ、紹介料と合わせて Vercel 有料プランの費用を上回る)。

### 始めるのに必要なもの
| もの | 環境変数 | 誰が |
|---|---|---|
| Stripe のアカウントと本人確認 | — | あなた |
| Stripe の秘密鍵(sk_live_…) | `STRIPE_SECRET_KEY` | あなたがクリップボードにコピーし、Claude が入れる(画面には出さない) |
| 購入の鍵に署名する乱数 | `LICENSE_SECRET` | Claude が作る |
| 値段 | `PRO_PRICE` | あなたが決め、Claude が入れる |
| 特定商取引法の表記(名前・住所・電話・メール) | `SELLER_NAME` `SELLER_ADDRESS` `SELLER_PHONE` `SELLER_EMAIL` | あなた。住所・電話は「請求があれば遅滞なく開示」にもできる |

### 確かめること
- テスト用の鍵(sk_test_…)で、買う → 使えるようになる、までを先に試す
- 本番の鍵に替えたら、自分で1回買って、返金できるかも確かめる
